It is a two-page website built with HTML, CSS, and JavaScript. The website is two-paged, one being the main index and the other one having crime, thriller and suspense books, with some info about them along with their reviews. The site is Halloween-themed with skeletons and carved pumpkins :)

<h3>Running It</h3>
The website is simply deployed on GitHub Pages and can be run using this link: <br>
https://legendplayz83.github.io/potato-portfolio/

On the website, the colour theme is violet and orange, with lots of pumpkins, skulls, and ghosts relating to the Halloween theme :D

<h3>Tech Stack</h3>
-index.html: HTML is used to create the structure of the spooky-reads homepage. It organises the webpage into a navigation bar, a hero section, and a footer. The hero section contains the website title, along with a short introduction to its collection of crime, thriller, and suspense books, decorative images of a ghost and skeleton, and a button linking to the book recommendations page.<br>
<br>
-books.html: HTML is used to provide the structure and content of the spooky-reads website. It organises the webpage into a navigation bar, a main heading, a book recommendation grid, and a footer. The HTML elements such as headings, paragraphs, images, and containers are used to display book covers, titles, authors, ratings, and short descriptions about em.<br>
<br>
-CSS is used to design the Spooky Reads website and create a spooky, Halloween-inspired theme. It sets a dark background, purple sections, and orange accents to maintain a consistent visual style throughout the page. The Flexbox arranges the homepage elements in order, while CSS Grid organises the book recommendations into responsive cards that adjust to different screen sizes. (for laptop, phone, tablet, or anything)<br>
<br>
-JavaScript is used to display the book ratings in a dynamic style on the spooky-reads website. It selects all elements with the stars class and fetches each book's numerical rating using the data-rating attribute. The program then rounds the rating to the nearest whole number to determine how many filled stars to display, using filled stars for the rating and empty stars for the remaining positions.
