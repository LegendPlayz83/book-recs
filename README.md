It is a two-page website built with HTML, CSS, and JavaScript. The website is two-paged, one being the main index and the other one having crime, thriller and suspense books, with some info about them along with their reviews. The site is Halloween-themed with skeletons and carved pumpkins :)

<h3>Running It</h3>
The website is simply deployed on GitHub Pages and can be run using this link: <br>
https://legendplayz83.github.io/potato-portfolio/

On the website, the colour theme is violet and orange, with lots of pumpkins, skulls, and ghosts relating to the Halloween theme :D

<h3>Inspiration</h3>
Since Halloween is round the corner, why not give the readers some book suggestions?
